# wall-fade 取证报告：地下转视角整面墙变透明

用户现象：地下某 y 以下，滑动拖屏转视角时概率一整面墙不加载变透明，能看到邻区块
内部（矿洞/岩浆），视角回正常恢复。26.1 MC Java 的 Rust 重写（xiaocongyu66/rustcreate）
真机渲染波。

## 病灶面清单逐面取证

### 面 1：frustum 剔除的 chunk AABB —— **实锤，定性为本仓剔除 bug**

世界 y 域与几何事实链：

- `game/mcv_core/src/lib.rs:29-32`：`WORLD_MIN_Y = -64`、`WORLD_MAX_Y = 320`
  （overworld 26.1 世界带 -64..320）。
- `game/mcv_mesher/src/mesher.rs:555-561`（v6 注释）：**顶点 y 为绝对世界 y**
  （层/格局部量 + `WORLD_MIN_Y`），上传 origin 的 y 分量恒 0。即每个区块批次
  含 geometry y ∈ [-64, 320)。
- `engine/mcv_render/src/gpu.rs:941-945`（`build_batch_entry`）批次剔除 AABB：

```rust
let c_aabb = (
    c_origin,                                                        // y = 0.0
    Vec3::new(c_origin.x + 16.0, 256.0, c_origin.z + 16.0),          // y ≤ 256
);
```

  AABB y 域写死 `[0, 256]`——**1.18 前旧世界高的残留**，比真实几何带
  `[-64, 320)` 低丢 64 层、高丢 64 层。y<0（深板岩层）的全部几何在剔除框外。

触发机制（对齐症状逐条）：

- 相机在 y<0（如矿井 y=-40），区块 AABB 整片悬在相机上方。微俯视角（拖屏时
  典型 pitch≈-8°，fov_y≈1.2 半角 34.4°）下视锥上平面在 32 格前仅到
  y = -40 + 32·tan(26.4°) ≈ -24：AABB 底 y=0 高出修正面 24+ 格 →
  `Frustum::intersects_aabb`（gpu.rs:3361-3362 逐批次判定）返回 false →
  **整个批次（≈一整个区块列）被剔除** → 「一整面墙」粒度吻合。
- 被剔除墙后方的区块距离更远、俯角更缓（如 96 格处.atan(40/96)≈22.6° < 26.4°）
  仍在视锥内照常绘制 → 隔着消失的墙**看到邻区块内部矿洞/岩浆**（实为更远处
  合法绘制面），症状吻合。
- 「概率 + 转视角触发 + 视角回正恢复」：`intersects_aabb` 是**逐帧纯函数**，
  无状态残留——pitch/yaw 连续变化中 AABB 恰好滑出视锥即消、摇回即现；
  y 越深消的视角区间越宽（y=-40 时 pitch < +19° 全消），故「地下某 y 以下」
  才显著，地表（eye y>0，AABB 覆盖眼高）永不触发。
- y>256 侧同病（云顶/山顶方块 256..320 亦可被误剔除），同修覆盖。

定性与原版对照：原版 26.1 按 24 个 render section（-512..2031 的 section 立方）
逐节 AABB 剔除，覆盖真实几何带——**不存在**此剔除；本仓批量整列批次路径里
AABB 域写死旧世界高，属本仓 bug，修正为世界带对齐（原版对齐优先）。

### 面 2：邻 chunk 边界面判定 —— 排除

- `game/mcv_mesher/src/mesher.rs:186-217`（`block_at`）：x/z 越界折入邻块，
  邻块未加载 → `BARRIER` 哨兵（实心）→ 贴边面**保留**而非剔除，不产生透明墙。
- #174「树缺一边树叶」先例实为跨界树双侧重放（f507f518）与 evicted/pool 治理
  （8be7d03b/9c429c88），与边界面剔除无关；#159 mesh 三段并行竞态若在，
  症状需 remesh 才恢复，不会「转视角即恢复」——与本证时序特征矛盾。

### 面 3：sub-chunk/mask y 绕回 —— 排除（同上时序反证）

mask/深 y 索引 wrap 需区块 re-mesh 才可能变化；症状随视角逐帧可逆，
属渲染剔除面而非网格数据面。且 #66/#68/#71 先例均由 mesher 测试面锁住，
本波不改 mesher 语义（黄金件零破坏前提）。

## 修复与回归

- 修：`build_batch_entry` 批次 AABB y 域改为世界带
  `[WORLD_MIN_Y, WORLD_MAX_Y)`，提为纯函数 `chunk_cull_box` 便于锁测。
- 回归（`engine/mcv_render/src/gpu.rs` 单测，无 GPU 依赖，CI 常跑）：
  1. 批次盒 y 域锁 -64..320；
  2. 真机病理复现双向锁：eye y=-40、pitch -8°、2 区块前批次——
     旧 `[0,256]` 盒被误剔除（守护不用错误域）、世界带盒可见
     （守护不再反向过度剔除）。
- 红线：不动 mcv_light；不改 mesher 输出字节（黄金件语义零破坏——改动仅
  在渲染剔除面，顶点流零字节变化）。
